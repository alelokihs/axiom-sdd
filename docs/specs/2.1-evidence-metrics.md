Authorized by the maintainer on 2026-10-06. Scope: local read-only structured task metrics,
methodology guidance, preservation fix, stdlib tests, version 2.1.0 and rollout to an existing consumer.
No model-cost claims, productivity ranking, automatic delegation or release decisions.

Observed motivation: a consumer had repeated coordination messages while real-provider acceptance
remained unproven; simulated integration passing is a separate fact. An independent code audit found

must remain synthetic; private channels and evidence must not be published.

## Tasks / ownership
- M1 metrics agent: cli/axiomcli/metrics.py and tests/test_metrics.py. Read-only report from optional
  sdd/progress.json. Strict versioned JSON, per task owner/next_action/blocker/required_mode,
  chronological evidence observations (at, path, sha256, mode, passed, failed, skipped).
  Verify current contained regular file digest, reject symlinks/outside paths, malformed/future dates.
  Distinguish no evidence, invalid evidence, incomplete checks, synthetic vs real requirement.
  Identical evidence digest+mode+counts observations never refresh last substantive progress.
  Report age/stale after configurable hours; do not equate matching metadata with independently
  verified execution. Missing optional progress file => report unavailable, no inference from prose.
- M2 composer agent: preserve existing sdd/profile.yaml and accurate copied-file reporting; tests.
- M3 coordinator: CLI metrics integration, docs/templates/gates, version/changelog, review and release.

## Acceptance
1. Repeated observations of unchanged evidence never reset progress age.
2. Missing/invalid inputs never count as completed; all-skipped and synthetic-only checks cannot
   satisfy real acceptance. Passing checks remain evidence-supported claims, not release approval.
3. No credentials/prose evidence contents in report; paths stay inside consumer; command never writes.
4. Install/update preserve project-owned bytes and refresh framework-owned files.
5. Deterministic stdlib tests and actual consumer report/update verification recorded before release.
