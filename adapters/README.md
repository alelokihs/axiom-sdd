# AI Runtime Adapters

The core is runtime-agnostic. Adapters translate it into each vendor's native mechanisms —
instruction files, command shortcuts, playbooks. **No adapter duplicates methodology**: adapter
files are thin pointers into `sdd/` plus the minimal "locks" that must survive even if the
runtime loads nothing else.

| | [Claude](./claude/ADAPTER.md) | [Copilot](./copilot/ADAPTER.md) | [Devin](./devin/ADAPTER.md) | [Codex](./codex/ADAPTER.md) |
|---|---|---|---|---|
| Native instruction file | `CLAUDE.md` | `.github/copilot-instructions.md` | Playbooks + Knowledge | `AGENTS.md` (root) |
| Reusable commands | `.claude/commands/*.md` | `.github/prompts/*.prompt.md` | playbook per flow | prompt discipline (no native slash files) |
| Runs commands/tests | yes | yes (agent mode) | yes | yes |
| Session persistence | per-session + memory file | per-session | long-running, checkpoints | per-task (cloud) / session (CLI) |
| Autonomy level | interactive→agentic | interactive/agent mode | high (long tasks) | high (delegated tasks) |
| Adapter emphasis | subagent roles, hooks | small context, explicit locks | boundaries, checkpoints, evidence | AGENTS.md as single entry |
| Model tier resolution | Haiku / Sonnet / Opus | chat model picker | effort routing (managed) | mini / standard / max-reasoning |

## Contract every adapter honors

1. Entry file(s) point to: `sdd/sdd.yaml`, `sdd/agents/README.md`, `sdd/constitution.md`,
   `sdd/guardrails.md`, active specs.
2. The locks (restated verbatim, ≤ 6 lines — the tolerated duplication): never request→code ·
   only authorized tasks · never invent (UNKNOWN/ASSUMPTION/NEEDS_CONFIRMATION) · never raise
   your own change budget · divergence is recorded, never silently fixed · no secrets, no
   destructive git.
3. Command shortcuts map 1:1 to the [ready prompts](../../examples/prompts/README.md).
4. A `## Model tiers` table resolving `fast` / `balanced` / `frontier` to concrete models —
   consumed by [bootstrap/model-selection.md](../bootstrap/model-selection.md).
5. Generated by bootstrap; regenerating is safe (adapter files are framework-owned).

Adding a runtime = one folder here + one generator section in
[bootstrap/BOOTSTRAP.md](../bootstrap/BOOTSTRAP.md). Core never changes.
